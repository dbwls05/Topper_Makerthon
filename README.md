# NUDGE · 지원금 AI 도우미

> **알아서 찾고, 끝까지 챙겨요.**
> 내 상황에 맞는 정부 지원금을 발견하고, 신청 준비까지 놓치지 않도록 곁에서 챙겨주는 AI 동행 서비스

AI 동행 메이커톤 출품작입니다.

## 프로젝트 소개

NUDGE는 **"나에게 맞는 지원금이 뭐지?"에서 "신청 완료"까지** 전 과정을 한 곳에서 도와주는 웹 서비스입니다.
내 지역·나이·소득·가구 형태·취업 상태·관심 분야를 알려주면, 그에 맞는 지원금을 골라주고,
마감이 다가오면 알려주고, 신청에 필요한 서류를 하나씩 체크할 수 있게 도와줘요.
헷갈리는 용어나 서류는 AI 도우미 **NUDGE**에게 바로 물어볼 수 있습니다.

## 왜 만들었나요

- 지원금은 **종류가 매우 많고 여러 기관에 흩어져** 있어서, 내가 받을 수 있는 게 뭔지 알기 어렵습니다.
- 대상·소득·지역 같은 **신청 조건이 복잡**해서 나에게 해당되는지 판단하기 힘듭니다.
- 신청하려면 **어떤 서류를 준비해야 하는지**, **언제까지인지**를 따로 찾아봐야 해서 마감을 놓치기 쉽습니다.

> 그래서 "찾기 → 이해하기 → 신청 준비 챙기기"를 하나의 흐름으로 묶었습니다.

## 어떻게 해결하나요

| 단계                     | 하는 일                                                           | 관련 화면               |
| ------------------------ | ----------------------------------------------------------------- | ----------------------- |
| 1. 나를 알려주기         | 4단계 맞춤 프로필로 내 상황을 입력하면 분석해서 저장              | 맞춤 프로필, 마이페이지 |
| 2. 나에게 맞는 지원 찾기 | 프로필 기반 추천 + 정부24 지원금 검색·필터                        | 홈, 혜택 검색           |
| 3. 궁금한 건 AI에게      | 지원 조건·서류를 쉬운 말로 설명, 여러 지원 비교, 이미지 첨부 질문 | AI 에이전트             |
| 4. 신청 준비 챙기기      | 관심 혜택 담기 → 필요 서류 체크리스트 → 준비 현황 확인            | 서류 관리, 홈           |
| 5. 놓치지 않기           | 마감 임박 지원 D-day 표시, 알림                                   | 홈, 상단 알림           |

## 주요 화면

| 화면              | 경로                | 설명                                                                  |
| ----------------- | ------------------- | --------------------------------------------------------------------- |
| 회원가입 / 로그인 | `/signup`, `/login` | 이메일 가입 (이름·전화번호 수집)                                      |
| 맞춤 프로필       | `/profile/setup`    | 지역, 출생 연도, 소득, 가구 형태, 취업 상태, 관심 분야를 4단계로 입력 |
| 홈                | `/home`             | 신청 가능한 지원금, 마감 임박 지원, 신청 준비 현황, 프로필 카드       |
| 혜택 검색         | `/search`           | 정부24 공공서비스 데이터 검색·필터, 관심 혜택 담기                    |
| AI 에이전트       | `/agent`            | 지원 찾기·비교·신청 관리를 대화로 도와주는 NUDGE                      |
| 서류 관리         | `/documents`        | 담은 지원금별 필요 서류 체크리스트, 서류 질문은 NUDGE로 연결          |
| 마이페이지        | `/mypage`           | 내 프로필 확인·수정                                                   |

## 이렇게 만들었어요 (설계 포인트)

- **AI는 DB에 있는 지원금 안에서만 답합니다.** 에이전트는 내 프로필과 DB의 지원금 후보를 함께 받아서 그 안에서만 답하도록 해, 없는 지원금을 지어내는 일을 줄였어요.
- **실제 공공 데이터를 씁니다.** 공공데이터포털의 정부24 공공서비스 API를 동기화해 지원금을 채웁니다.
- **개인정보는 본인만 볼 수 있어요.** 소득 등 민감한 프로필은 Supabase RLS(행 단위 접근 제한)로 본인 행만 읽고 쓸 수 있게 했습니다.
- **AI 키는 브라우저에 없습니다.** OpenAI 호출은 Supabase Edge Function이 대신하고, 로그인 확인과 하루 호출 횟수 제한(기본 30회)을 거칩니다.
- **Supabase가 없어도 화면은 돌아갑니다.** 키를 채우지 않으면 데모 모드로 동작해서 누구나 바로 화면 흐름을 볼 수 있어요.

## 기술 스택

- **프론트엔드**: React 19, React Router 7, Vite
- **백엔드**: Supabase (Auth, Postgres + RLS, Edge Functions)
- **AI**:
- **데이터**: 공공데이터포털 정부24 공공서비스 API

## 실행 방법

```bash
npm install
cp .env.example .env   # 값 채우기 (아래 표 참고)
npm run dev            # http://localhost:5173
```

`.env`의 Supabase 값이 비어 있어도 데모 모드로 실행됩니다. (가입·프로필은 저장되지 않아요.)

| 변수                        | 누가 필요한가   | 용도                                                              |
| --------------------------- | --------------- | ----------------------------------------------------------------- |
| `VITE_SUPABASE_URL`         | 모두            | Supabase 프로젝트 URL                                             |
| `VITE_SUPABASE_ANON_KEY`    | 모두            | Supabase anon(public) 키                                          |
| `DATA_GO_KR_KEY`            | 동기화 담당자만 | 공공데이터포털 인증키                                             |
| `SUPABASE_SERVICE_ROLE_KEY` | 동기화 담당자만 | `grants` 쓰기용 키. **RLS를 무시하는 강력한 키라 공유·커밋 금지** |

⚠️ `VITE_`로 시작하는 값은 브라우저에 그대로 들어갑니다. 비밀 키에는 절대 `VITE_`를 붙이지 마세요. `.env`는 커밋되지 않습니다.

## 프로젝트 구조

```
src/
├─ api/          화면이 데이터를 가져오는 창구 (benefits.js)
├─ components/   공통 컴포넌트 (레이아웃, 알림 메뉴, 프로필 폼 …)
├─ constants/    프로필 선택지 등 상수
├─ hooks/        공용 훅 (useApi)
├─ lib/          Supabase 클라이언트, 로그인 사용자, 저장한 혜택
├─ pages/        라우트별 화면
└─ styles/       화면별 CSS
scripts/         정부24 동기화 스크립트
supabase/        SQL 스키마·시드, Edge Function(ai-agent)
```
